# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment and personal attacks are not tolerated.

Report unacceptable behaviour to the maintainers through the repository's private security advisories or by contacting a maintainer directly. Reports are handled confidentially.
